# Sabiá Viagens

Projeto Integrador do curso Técnico em Desenvolvimento de Sistemas do IFTM. O site usa HTML, CSS, JavaScript e um catálogo em JSON, com consulta ao IBGE.

Para executar, abra um terminal nesta pasta, rode `python -m http.server 8000` e acesse [http://localhost:8000/index.html](http://localhost:8000/index.html). A consulta ao IBGE e os recursos externos precisam de internet.

Reservas e pagamentos são simulados. Os dados locais ficam no navegador e não são compartilhados automaticamente entre dispositivos.
